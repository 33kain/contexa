What I changed
- build.mjs: new `changelogFault(text, version)` — returns the failure message,
  or null — plus the block below it that runs it over CHANGELOG.md against
  VERSION and pushes the result into `fails`, so a mismatch exits the build
  non-zero like every other invariant there. It matches the first `## <version>
  —` heading only, so `## Repository, ... —` is skipped, and a changelog with no
  version heading fails closed.
- extension/test.mjs: new section before the final summary that lifts
  `changelogFault` out of build.mjs by source (build.mjs is a script — importing
  it would run a build), then covers the passing case (the real CHANGELOG.md
  against the real manifest version), the failing cases (bumped manifest,
  changelog left behind, no version heading, empty input), the skip rule, the
  newest-not-oldest rule, the message content, and that build.mjs actually wires
  it into `fails`.
