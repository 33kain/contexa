What I changed

- build.mjs — added `changelogVersion(src)` (a pure helper that returns the version of the first
  `## <version> —` heading, skipping prose headings like `## Repository, …`) plus, in the top-level
  invariant block right after the worker-BUILD check, the comparison that pushes `changelog mismatch: …`
  onto `fails` when it disagrees with the manifest version (or `CHANGELOG.md has no …` when there is none).
- extension/test.mjs — added a build-guard block at the end of the suite: it lifts `changelogVersion` out of
  ../build.mjs by source (importing build.mjs would run the build), covers heading selection/skip/null,
  the passing case (real CHANGELOG.md vs real manifest.json) and the failing case (a stale heading), and
  asserts build.mjs actually wires the helper into `fails`.

Runs: `npm test` 2 times (plus one `npm run test:extension` on its own while iterating); `node build.mjs`
3 times — a green run, one deliberate red run with the newest heading temporarily set to 0.9.94 to see the
check fail (CHANGELOG.md reverted with `git checkout --` immediately), and a final green run.
