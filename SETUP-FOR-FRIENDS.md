# Installing CONTEXA (about 2 minutes)

Works in Chrome on a computer — not on phones. Free, no account, no API key.

1. Save the zip file, then right-click it → **Extract All**. Put the extracted
   folder somewhere you won't delete it (like Documents) — Chrome runs the
   extension straight from that folder.
2. In Chrome, type `chrome://extensions` in the address bar and press Enter.
3. Turn on **Developer mode** — the switch in the top-right corner.
4. Click **Load unpacked** (top-left) and pick the folder you extracted.
5. Go to claude.ai — if it was already open, refresh the page — and ask Claude
   anything. When the reply finishes, up to five suggestion chips appear
   under it.
6. Click a chip: it types a ready-made follow-up into your message box. Read it,
   change anything you like, and send it yourself. It never sends anything on
   its own.

Good to know:

- Free for up to 20 replies a day.
- Chrome may warn about "developer mode extensions" when it starts — normal for
  anything installed outside the Web Store, nothing to fix.
- To remove it: `chrome://extensions` → Remove.
